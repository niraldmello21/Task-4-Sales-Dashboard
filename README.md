# Task 4 - Sales Dashboard

## Objective
Designed an interactive Sales Performance Dashboard using Microsoft Power BI to help business stakeholders analyze sales performance and trends.

## Tool Used
- Microsoft Power BI

## Dataset
Sales Financial Dataset

## Dashboard Features
- Total Sales KPI
- Total Units KPI
- Sales trend by Year and Month
- Top 10 Items by Units Sold
- Top 10 Items by Sales
- Sales by Region
- Sales by Salesperson
- Sales by Manager
- Interactive Region, Item and Salesperson filters
- Key business insights

## Key Insights
- Sales performance varies across different time periods.
- Different items contribute differently to total units sold.
- Regional, salesperson and manager performance can be compared.
- Interactive filters help identify sales trends and better-performing items.

## Files Included
- `Task 4.pbix` - Power BI dashboard

## Conclusion
The dashboard provides an interactive view of sales performance and helps identify trends and better-performing products, regions and sales personnel.
